This is a static Vite application and can be deployed on:

* Render

* Netlify
* Cloudflare Pages
* GitHub Pages

For Render:

```text
Service       → Static Site
Build Command → npm install && npm run build
Publish Dir   → dist
```

## 🔧 Customization

Most portfolio content is managed from:

```text
src/data.js
```

Update:

* `profile` → personal/contact information
* `projects` → featured projects
* `skills` → technical skills
* `stats` → portfolio statistics
* `timeline` → experience
* `achievements` → XP/achievements

For visual changes, edit:

```text
src/styles.css
```

Place personal assets in:

```text
public/assets/
```
