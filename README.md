# Abbas — Card-Themed React Portfolio

A production-ready React/Vite portfolio implementation inspired by the provided card-themed reference website and customized with the supplied portfolio content.

## Stack

- React 19
- Vite
- Modern CSS (no UI framework)
- Responsive/mobile-first behavior
- IntersectionObserver reveal animations
- Interactive skill-card shuffling

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy

This is a static Vite build. Deploy the generated `dist/` folder to Vercel, Netlify, Cloudflare Pages, GitHub Pages, or any static host.

## Personal assets

Swap `/public/assets/your-image-here.jpg` with your own image and replace the placeholder project screenshots as needed.

The exact personal links and project data live in `src/main.jsx` so the portfolio can be edited without digging through the stylesheet.
